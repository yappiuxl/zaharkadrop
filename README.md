# Zaharka Drop

## Деплой на Render
1. Залей репо на GitHub.
2. Render → New → Web Service → подключи репо.
3. Build Command: `npm install`
4. Start Command: `node server.js`
5. Instance Type: Free
6. Готово. Открой URL.

**Важно:** free-инстанс засыпает через 15 мин бездействия, данные в памяти теряются (если нет диска). Используй кнопку **Экспорт** в шапке для бэкапа и **Импорт** для восстановления.

## Игра
- Введи ник при первом заходе.
- Стартовый баланс: 100 ₽.
- Вкладки: Инвентарь | Кейсы | Апгрейдер | Батлы.
- Батлы: создай (выбери до 20 кейсов, оплати сумму), друг заходит (платит столько же), оба крутят, у кого сумма дропа больше — забирает все предметы с обеих сторон.
